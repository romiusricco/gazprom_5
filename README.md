# Образовательный портал Газпромбанка о финансах

Образовательный портал Газпромбанка с материалами о финансах.

## Быстрый старт

Откройте `index.html` в браузере.

## Стек

- HTML
- CSS

## Структура проекта

- `css/blocks/` — стили компонентов: `article-card`, `cat_nav`, `container`, `footer`, `header`, `hero`.
- `css/global/` — глобальные стили: шрифты и сброс стилей.

## О доработке

Исходник — ветка `base/original` (тег `original-source`).  
Добавлены SVG-спрайт и лицензия MIT.
